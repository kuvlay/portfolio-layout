# Portfolio Grid · HTML and CSS Exercise

A compact portfolio-style layout built with plain HTML and CSS. The page combines colored panels, SVG illustrations, an identity card, and section tiles to practice composition and layout.

**HTML5 · CSS3 · SVG**

[Portfolio](https://github.com/kuvlay)

## What is included

- A top row containing two illustrated panels and an identity card.
- Lower “Works” and “Fear & Failures” tiles.
- Separate stylesheet and local SVG assets.

## View locally

```bash
git clone https://github.com/kuvlay/portfolio-layout.git
cd portfolio-layout
```

Open `final.html` in a browser. No package installation, build process, environment variables, or backend are required.

## Files

| File | Purpose |
| --- | --- |
| `final.html` | Page structure and content |
| `finalstyle.css` | Layout, colors, and panel styling |
| `pen.svg`, `eye.svg` | Local illustrations |

## Scope and status

This is a static layout exercise. Tiles are visual content; there is no navigation system, form submission, or application backend. The identity card displays Kuvlay Naman and Delhi Technological University, with text sized to wrap within the panel. Browser layout and accessibility checks have not been run during this documentation update.
